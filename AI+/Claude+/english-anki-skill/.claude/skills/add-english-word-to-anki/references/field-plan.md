## Field plan

This table explains how to get value for each field.

| Field                      | Value                                                                                                                                                             | Created by            | Remarks                                                                                                                                                                              |
|----------------------------|-------------------------------------------------------------------------------------------------------------------------------------------------------------------|-----------------------|--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| English                    | base form of the word (see SKILL.md step 2.1.4)                                                                                                                   | Claude                | Prefixed with `a`/`an` (nouns) or `to` (verbs) to dodge Anki's exact-duplicate warning, e.g. "a bucket", "to conquer"; ignored when matching duplicates (see SKILL.md step 2.2)      |
| Transcription              | American IPA                                                                                                                                                      | Claude                | —                                                                                                                                                                                    |
| Definition                 | concise dictionary-style definition                                                                                                                               | Claude                | —                                                                                                                                                                                    |
| Definition-wq-generated    | empty                                                                                                                                                             | —                     | Obsolete, from "Word Query" addon, unused now                                                                                                                                        |
| Picture                    | empty                                                                                                                                                             | —                     | —                                                                                                                                                                                    |
| Russian                    | translation                                                                                                                                                       | Claude                | —                                                                                                                                                                                    |
| Example-my                 | empty                                                                                                                                                             | —                     | —                                                                                                                                                                                    |
| Example-real-life          | HTML bullet list `<ul><li>sentence (Source)</li></ul>`, one `<li>` per sentence, Source title-cased, word/phrase wrapped in `<b>` where it occurs in the sentence | User (input)          | Format example: @"assets/Example of field Example-real-life.html". On duplicate (see SKILL.md step 2.2), a new `<li>` is appended inside the existing `<ul>` instead of replacing it |
| Synonym1                   | simplest synonym, picked from Synonyms                                                                                                                            | Claude                | If no synonym exists, leave empty and tag the note `~api::absent::synonym1` (see SKILL.md step 2.4)                                                                                  |
| Synonyms                   | up to 10 synonyms (if any exist)                                                                                                                                  | Claude                | If none exist, leave empty and tag the note `~api::absent::synonyms` (see SKILL.md step 2.4)                                                                                         |
| Antonym1                   | simplest antonym, picked from Antonyms                                                                                                                            | Claude                | If no antonym exists, leave empty and tag the note `~api::absent::antonym1` (see SKILL.md step 2.4)                                                                                  |
| Antonyms                   | up to 10 antonyms (if any exist)                                                                                                                                  | Claude                | If none exist, leave empty and tag the note `~api::absent::antonyms` (see SKILL.md step 2.4)                                                                                         |
| Tense                      | empty                                                                                                                                                             | —                     | —                                                                                                                                                                                    |
| Comment                    | empty                                                                                                                                                             | —                     | —                                                                                                                                                                                    |
| Examples1-generated        | HTML bullet list `<ul><li>sentence</li></ul>`, one `<li>` per sentence, up to 10 example sentences using the word                                                 | Claude                | Same list format as Example-real-life, but without a source (Claude-generated, not from a real-life source)                                                                          |
| Examples2-generated        | empty                                                                                                                                                             | —                     | —                                                                                                                                                                                    |
| Examples3-generated        | empty                                                                                                                                                             | —                     | —                                                                                                                                                                                    |

| Definition-audio-generated | mp3 of Definition field                                                                                                                                           | User (HyperTTS addon) | —                                                                                                                                                                                    |
| Synonym1-audio-generated   | mp3 of Synonym1 field (if not empty)                                                                                                                              | User (HyperTTS addon) | —                                                                                                                                                                                    |
| Synonyms-audio-generated   | empty                                                                                                                                                             | —                     | —                                                                                                                                                                                    |
| Antonym1-audio-generated   | mp3 of Antonym1 field (if not empty)                                                                                                                              | User (HyperTTS addon) | —                                                                                                                                                                                    |
