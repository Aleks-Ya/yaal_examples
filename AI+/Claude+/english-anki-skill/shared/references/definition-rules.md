# Definition field — wording rules (shared)

The single home for how the `Definition` field of an `En-word-or-sentence` note is worded. Both
skills reach it through `field-plan.md`'s Definition row and the backfill routine (step B2). The
value is a short, simple, dictionary-style definition: **one** short, plain, learner-friendly
sentence (a fragment is fine).

## Use the simplest possible words

Use the most common, everyday words an English learner would already know, so the definition is easy
to understand. Whenever a simpler word would work, use it instead of a harder or more technical one,
and never use jargon.

## Then be as concise as possible

With that simple wording, use the shortest phrasing that still conveys the core sense. Drop
non-essential detail — exact dates, sub-clauses, "relating to…" filler.

## Never use the headword

Never use the headword or any word sharing its root — derived, inflected, or same-family forms
(e.g. *decision* → don't use "decide"; *Ottoman* → don't use "Ottoman"). Describe the thing instead
of naming it, rephrasing around it even for proper adjectives/nouns.

## Examples

- *beggar* → "a person who is very poor and lives by asking others for money or food"
- *Ottoman* → "of a Turkish empire that ruled much of the Middle East and southeast Europe from
  about 1300 to 1922"
  — **not** "relating to the Ottoman Empire, a Turkish empire that existed from the late 13th
  century until 1922, ruled by sultans"
