# MCP Inspector

Run: `npx @modelcontextprotocol/inspector`

Run connected to a given MCP server:
- Everything Server: `npx @modelcontextprotocol/inspector npx -y @modelcontextprotocol/server-everything`
- Anki MCP Server: `npx @modelcontextprotocol/inspector npx -y @ankimcp/anki-mcp-server --stdio`
