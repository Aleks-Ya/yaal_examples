# PlantUML CLI
 
## Install
Latest version: `brew install plantuml`
Obsolete version: `sudo apt install -y plantuml`

## Commands
Version: `plantuml -version`

### Render to PNG
To current directory: `plantuml diagram.puml` -> `diagram.png`
To given directory: `plantuml -o out diagram.puml` -> `out/diagram.png`
