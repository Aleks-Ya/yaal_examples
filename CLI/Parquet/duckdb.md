# duckdb CLI

## Info
Site: https://duckdb.org
GitHub: https://github.com/duckdb/duckdb
PyPi: https://pypi.org/project/duckdb/

## Install
Latest version: `pipx install duckdb-cli`
Latest version (externally-managed-environment error): `pip install duckdb-cli`

## Command
Help: `duckdb -h`
Version: `duckdb -version`

## Operations
Help: `.help`
Quit: `.quit`
List tables: `.tables`
