# visidata CLI

## Info
Site: https://www.visidata.org
GitHub: https://github.com/saulpw/visidata

## Install
Latest version: `pipx install --preinstall pyarrow visidata`
Latest version (externally-managed-environment error): `pip3 install -U visidata`
Outdated version: `sudo apt install visidata`

## Commands
Help: `vd --help`
View a Parquet file: `vd my.parquet`

## Hotkeys
Return back after `Enter`: `q`
