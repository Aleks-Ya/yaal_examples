# Coursier CLI

## Install
Brew does NOT work: `brew install coursier/formulas/coursier`
Use: https://get-coursier.io/docs/cli-installation

Help: `cs help`
Help about a command: `cs update --help`
Version: `cs version`

## Commands
List installed apps: `cs list`
Update all apps: `cs update`

### Setup
Help: `cs setup --help`
Help full: `cs setup --help-full`
